What's running under the hood

Kernel path
eBPF · TCX / cgroup v2
CNI dependency
None
Enforcement model
Leased, observe-first
Deployment
Helm · one agent DaemonSet
Diagnose

Nine-stage Congestion Map

A pictorial, cluster-wide view of exactly where the Linux network stack is under pressure — NIC ring, NAPI, IP, conntrack, TCP queues, qdisc — colored live, with per-node drill-down instead of a bare healthy/unhealthy badge.

Capture

Live packet capture, decoded

Wireshark-style layered decode, multi-node bulk capture, automatic pod/VM attribution by IP, saved filter presets, and JSON/CSV/pcap export — streamed straight into the dashboard, no separate tooling.

Enforce

Controls that expire themselves

IP, CIDR, port, UID, process, DNS-name, and TLS-SNI deny, plus rate ceilings — every one lease-governed. Enforcement reverts to observe automatically on lease expiry, agent disconnect, or controller restart.

Integrate

AI-native, not a black box

A 133-tool MCP server, ChatOps for Slack and Teams, heuristic-first briefs and explanations, and CEF/syslog/OTLP export into the SIEM your team already runs.
